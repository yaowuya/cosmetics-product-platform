# 化妆品企业产品展示平台 V1 — 前端技术设计

交付两个入口：客户打开公开 H5 看已发布内容，运营在 PC 后台改草稿。后台预览使用与访客相同的 H5 展示组件，但两者的取数入口和权限不同。V1 不交付小程序，不把微肽资料或原型里的账号切换器打包为生产功能。

### 架构主线

访客端接收页面、产品或案例的公开投影；管理端接收稳定条目 ID、线上版本、草稿修订和当前权限。一个产品在目录中可以出现多次，但后台勾选和反馈均以产品 ID 为单位。不能用列表下标、配方编号或分类名定位发布目标。

最小交付单元依次验证：公开目录能显示真实已发布产品；后台能保存并预览未发布改动；有权者才可让两个入口读到同一新版。H5 的展示组件接收视图数据，不自行读取账号或决定能否访问。公开页面与私有预览各有独立的取数入口，复用的是渲染，不是权限上下文。

#### 组件、路由与 API 模块

公开页面、管理页面和私有 H5 预览使用可分辨的路由。四个公开页对应 `/`、`/catalog`、`/cases`、`/contact`；产品详情通过 ID 打开，深链不依赖先访问目录。管理区以 `/admin` 开头，产品与案例分列表，详情以稳定 ID 定位。路由名是实现映射，不新增业务入口。

公开客户端只调用 public 读接口，即使浏览器已有编辑身份也不切换数据源。管理客户端仅向受信同源入口携带会话及防跨站请求信息。保存后，管理页在手机宽度预览区用条目 ID 和已保存的期望修订打开私有 H5 预览；不在 URL 中携带会话令牌或草稿正文。

条目 ID 必须有效，修订号必须是非负整数。缺失或格式不合法时，清空画面、不发请求，并提示从编辑页重新打开。服务端仍独立校验参数、权限及修订（见[私有接口](backend.md#接口权限与兼容边界)）。`409` 提示回到草稿重新核对，不改读新版或线上版。

守卫只负责导航体验，不是权限边界。会话失效返回登录，首次改密后才进入工作区；403 刷新能力并说明操作未执行。公开详情收到 404 不区分不存在、草稿或下架。后端返回的字段错误定位到编辑位置；发布服务端回执是唯一成功依据。具体契约见[后端接口](backend.md#接口权限与兼容边界)。

#### 状态管理

- **访客浏览**：按板块记录本次浏览的分类、细筛、关键词和各栏滚动位置；分类变化时重置细筛与右侧位置。响应须匹配当前查询，避免慢返回覆盖新搜索。不承诺刷新后永久保留位置。
- **编辑**：区分未保存输入、已保存草稿、线上版和历史。显示修订来源；保存冲突保留未提交输入，允许对照最新草稿再保存。上传成功仅更新表单中的素材引用。切换条目前提示未保存改动。
- **私有预览**：切换条目或修订时立即清空旧画面，只在当前请求成功且条目 ID、修订号和本次请求均匹配时，才交给共享的 H5 组件。迟到的成功或失败结果都不改变当前画面和提示。会话失效或编辑权撤回时，清空预览，按当前会话状态提示重新登录或权限变化。
- **批量追加位置**：目标集合只含勾选的产品 ID；已有位置不重复，已有草稿不丢其他字段。标明「仅存草稿」并逐款反馈；不把成功款标为已发布。
- **批量发布**：检查针对勾选 ID 与各自草稿修订。将可发、缺项、无草稿分开，确认按钮显示可发数，零款禁用。仅发送已核对项。页面为每项保留请求键与处理状态；离开前提示未完成，关页不宣称整批取消。回到后台后按原回执或条目记录核对，不自动补发。超时显示「结果待核对」，修订冲突需要重新预览。
- **清理**：从未发布的草稿才显示确认删除。仍在线上须先下架；有历史且已下架的才开放归档。关联案例提示列出名称，取消时不调用写接口，归档也不修改案例。

#### Business Workflows

以下为 `business-flow`，不是原型演示。执行时使用独立浏览器会话：E 编辑、P 发布人、A 企业管理员、V 未登录访客。前置数据由真实账号通过后台创建，不从原型注入。每项按「准备 → 操作 → 重新进入验证 → 清理」执行；任务与用例由计划阶段绑定。

| Workflow ID | 来源 / 终态 | 角色及资源交接 | 有序阶段与终态证据 |
| --- | --- | --- | --- |
| WF-001 | §3.3、§3.6，缺图不能发布 | E → P → V；产品 ID、草稿修订 | 建立双位置线上产品，删长图并保存；预览缺图、检查不合格；V 两处仍见旧版。 |
| WF-002 | §3.6，合格版本上线 | E → P → V；沿用同一产品 ID | 补图、保存并核对修订；P 确认；刷新两个分类核对同一新版并溯源到本次日志。 |
| WF-003 | §3.6，恢复不等于回滚上线（[D-021](backend.md#decision-ledger)） | E（无发布权）、另一编辑会话、V；同一条目、历史版本、期望修订 | E 确认覆盖前由同事保存，恢复返回 409，重开仍是同事的草稿；E 核对最新修订并再次确认，恢复成功。重开可见新草稿，日志可查操作者和来源版本；E 尝试发布返回 403，V 仍见原线上版，其他条目未变。 |
| WF-004 | §3.3，仅追加草稿位置 | E → V；勾选的多个 ID | 准备已有位置、已有修改和未勾选对照；重复追加；重开核对不重复、不丢文案，线上不变。 |
| WF-005 | §3.6，部分成功及回执中断 | P → V；请求号、修订、版本 | 准备 8 款合格、1 款缺图、1 款无草稿；确认合格款。在一条已提交但未收到回执、后一条尚未发起时真实断开连接。重新进入后台，按原请求号核对或重试已提交款，不重复生成版本或日志；尚未发起的款不发布、不自动补发，跳过款保留原状。 |
| WF-006 | §3.7，撤权或停用拒绝操作 | A、P 分会话；目标账号 | P 保持编辑页打开，A 撤权；旧页发布失败，仍可编辑。账号停用后连保存也失败，历史发布不变。 |

| WF-009 | §3.6，归档保留历史 | P；曾发布的产品及案例 | 线上直接归档被拒；下架再归档，退出日常列表，重查版本和日志仍在。 |

| WF-012 | §3.3、§3.6，修订冲突 | 两个编辑会话、P；同一草稿修订 | 同时打开，先保存换图，再用旧修订保存文案；后者见冲突且保留输入。预览后他人再修改，旧预览不能确认发布。 |

| WF-014 | D-025，迟到响应不接管当前画面 | E；甲、乙的条目 ID、修订和请求结果 | 发起甲的预览并延迟其响应，再切到乙。切换时清空旧画面，乙先返回时只显示乙。放行甲的响应后核对画面和提示仍对应乙。重新进入核对两条草稿均未因预览改变。 |

每条记录实际方法、响应、稳定资源 ID、后继会话回读结果，不保存密码或 Cookie。清理通过真实下架、归档、删除首次草稿、复原权限，或销毁经授权的隔离测试部署；有发布历史的测试条目不能为了清理而绕开归档规则。无法安全制造真实中断时标记未验证，不用模拟回执代替。
