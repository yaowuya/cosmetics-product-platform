# V1 自测计划与用例

来源为[原始 PRD §三至五](../../../prd.md)，特别是 §五的 18 行测试建议。下表编号仅用于本轮结果对应，不替换既有任务、视觉门禁或 WF 编号。PC 视觉依据项目指定的 `prototype.html`，H5 依据交接包 `prototype/index.html`；不能把原型的模拟操作当成测试通过。

**执行顺序**：先核对基线、测试账户/库与产物 → 执行两个构建、单元及 MySQL 集成套件 → 用真实 Chrome 在两个本机实例执行下列用户操作 → 以重进、网络、审计和资源版本核对终态 → 停止一次性环境并分别报告通过、失败及环境阻塞。任何已有的绿色结果都不替代本轮执行。

**角色与数据**：A 仅治理，E 仅编辑，P 可编辑和发布，V/V2 是相互独立的匿名浏览上下文。样例企业只读；写入在全新、仅回环可达的一次性企业进行。所有业务资料经 UI 上传/录入，不直接改库或给浏览器注入业务数据。集成套件另用专用测试库；不触碰 3306 项目库或 `auto-ops`。测试名字和图片均为本轮合成资料。日志不记录 Cookie、口令、请求正文或 CSRF。

| 编号 | 原始场景／前提 | 操作 | 通过所需的观察结果 |
|---|---|---|---|
| PRD-01 | 微肽样例已按设计配置 | 用访客身份浏览四页，逐板块核分类，进入产品详情 | 导航顺序正确、四张海报、五板块共 43 个分类；详情有名称及五项资料、一张长图，无购买入口。 |
| PRD-02 | 第二企业空库、同一套构建、独立媒体/会话 | A 开通账号，E 设置护肤/彩妆/香氛、封面、海报、服务与联系并交 P 发布；分别重入两实例 | 第二企业只见自身内容，第一企业数量和资料未改。单机隔离不算真实异机交付。 |
| PRD-03 | 同一已发产品在两分类展示 | E 改功效并移除长图，保存、预览；P 检查；补图、检查、发布 | 缺图被明确指出、双位置仍为同一旧版；补齐后两处都指向同一新版详情。 |
| PRD-04 | 新品缺发布必填图 | 保存、检查；V 查目录、搜索和详情 | 工作稿保留，不能确认；三种公开入口均没有该新品。 |
| PRD-05 | 一款双位置产品同时有 live 和 draft | 分别按名称和配方编号查询；组合两个分类及线上/草稿筛选；加不匹配条件 | 命中为同一稳定 ID 且仅一行；不匹配时零行。 |
| PRD-06 | 产品和案例各有目标和未选对照 | 在两个 PC 列表分别新建、查找、编辑；P 从目标行检查并发布 | 保存和检查不公开；只有确认的目标上线，各自有回执及日志；对照稿不变。产品、案例分别留证。 |
| PRD-07 | 从未发布的产品和案例各一 | 两处先取消删除并重开，随后明确确认 | 取消不写；确认后查不到该条且删除审计含人和对象。 |
| PRD-08 | 产品/案例均有发布历史，产品有关联案例 | 核对线上禁止删除/归档；先下架再归档；筛出归档条目、查看版本和审计 | 下架后不能删除；归档后不在日常列表，历史仍在；归档产品不连带案例。 |
| PRD-09 | 甲已有目标分类，乙另有文字草稿，丙不选 | E 给甲乙追加同一位置，再执行一次，刷新后分别读取 | 不重复，乙保留原有文字和位置，丙完全不变，未生成新线上版。 |
| PRD-10 | 8 款合格、1 款线上但草稿缺图、1 款无新稿，另有 1 款合格不选 | P 仅勾选前十款，核对检查列表、按钮和确认结果；另验零合格选择 | 检查无写，按钮计数 8；仅八款各一份版本和审计，缺项、无稿、未选均不发布，零合格不能提交。清单对照产品名、编号和缺项。 |
| PRD-11 | 同批发布的两款各有旧版 | E 只把甲旧版恢复为草稿，重进两个条目及匿名端 | 仅甲有恢复记录及新稿；两款 live、乙的稿和历史均不动。 |
| PRD-12 | 一分类三款，其中细类只有一款 | 选细类，看计数，进详情再返回；按板块搜索后清空 | 分类总数仍为 3、筛选只一款；清空及返回恢复之前选择/位置。 |
| PRD-13 | 已发产品有两位置，另有独立已发案例引用它 | 打开影响名单，先取消再确认下架，然后按两位置、搜索、详情和案例复查 | 取消不变，确认仅移除产品；案例保留原图文，不暴露内部关联或产品跳转。 |
| PRD-14 | 无关联的定制案例 | 单独保存和发布，筛到仅一条并查看详情 | 不新建产品；一条只显示重点卡，没有空网格标题或产品链接。另核空结果、清除与手删空。 |
| PRD-15 | 联系条目有两张可区分的测试码及不同版本，服务卡独立 | 核对误发记录、历史恢复、访客回读、再次发布；从两个入口检查二维码 | 恢复只改稿；重新发布才换码，旧图无公开引用时失效；服务卡不回退。字节/离线解码与真实手机扫码分别记，不混算。 |
| PRD-16 | 普通 E、P 与仅治理 A，各有独立会话 | 核对能力；P 可发布自改稿，A 撤权，P 从保留页面操作；再停用，查日志 | 权限由后端判定；撤权不影响已发版，仍可编辑；停用后旧会话不可写；A 可追查治理事件。 |
| PRD-17 | 产品有线上和不同的指定修订草稿 | E 私有预览；两个独立 V 打开相同公开链接、尝试正常打开私有预览地址 | V 均仅见线上含配方编号，无管理权；E 取到正确保存修订；过期修订不得回退。 |
| PRD-18 | 真实窄屏手机、长图、可选渠道未填写 | 阅读并暂停轮播、切页、放大服务图、打开联系弹层、返回，检查安全区和可用渠道 | 图按比例且导航可用，暂停/恢复正确，缺项不出现。浏览器模拟另列，不能替代实际设备。 |

**补充回归**：轮播的正常切换/按住暂停，案例搜索保留/重置筛选的差别、独立联系入口、真实浏览器按钮键盘行为，修订竞争与发布幂等；对精确丢回执时序、真实手机、Docker/干净异机恢复分别检查前提。对受设备或正式素材限制的结论明确写出仍缺哪一项。

**判定与巡检**：实际断言不符为 FAIL；必要资源不存在为 BLOCKED；有明确本层实测但还缺另一子项为 PARTIAL，记录具体子项。每五分钟检查进程、完成记录与本轮测试服务；仅在确认意外退出、没有未核对写入时拉起该段。业务断言失败、缺正式设备或权限不触发无限重试。不修改产品代码或删改用例来制造通过。
