### 架构主线

输入是固定页面的 `{page, body}`、目录的 `{nodes, counts}`、列表的 `{items, total, page, page_size}` 和详情的 `{id, body}`。最小实现是原生页面直接请求、渲染这些形状。六页都依赖同一个公开源，两个列表都要处理异步覆盖与重试，因此集中实现公开 API 适配和分页协调，其余行为保留在各页。不引入框架、全局状态库、请求缓存或第三方组件库。

切换 Tab 或打开详情 → 页面读取公开数据 → 识别响应并转成显示模型 → 交给 WXML 原生组件。返回详情前的页面不会重新拉取列表；明确刷新或新建页面实例时拉取。不存在或已下架的详情显示退出入口；临时失败可重试。先核验目录到详情的纵切，再核验案例、首页和联系。

### 状态、并发与执行流程

- 目录先加载封面和树，默认选择首个有效板块和分类。板块、分类、子类按公开树及计数显示；每个板块记住页面内的筛选与滚动。分类切换时清空关键词与子类；搜索时只限定当前板块，不发送 `node_id`。无板块时不请求无范围的列表。
- 案例按现有标签和关键词搜索；清空时回到默认标签。案例首项为精选，其后为双列列表；追加不得重复创建精选。
- 列表在输入变更即撤销旧代次，160 毫秒后查询；并发用代次判定，不依赖取消回调顺序。只允许一个有效追加，同代失败保留已有行与页码；重试重发目标页。筛选、刷新或卸载后，旧结果不得覆盖当前结果。同 ID 不重复渲染。新筛选回顶部；详情返回保持目录的左右滚动、案例的页面滚动和已加载页。
- 首页空态不制造演示海报。轮播仅在多张有效海报、当前页可见、用户未触摸且尚未向下阅读时每 4,000 毫秒自动翻页；图片出错可跳过，恢复或切页时不累积计时。
- 联系以请求结果区分未发布和加载失败。有公开数据才呈现相应动作；兼顾微信 API 失败提示和可手动选中的文本。预览使用微信原生图片预览，不自行增加保存到相册权限或邮件发送。

### 接口、权限与兼容边界

所有 JSON 读请求为匿名 `GET`，不设置验权头、会话凭据或业务 Cookie，不自动重试任意地址。配置只接受一个源，不允许路径、账号、查询、片段；开发版可使用明确的本地地址，体验与正式版必须使用已配置的公开 HTTPS 域名，不能继承开发配置。未配时提示，不换地址。

| 端点 | 输入 | 处理边界 |
| --- | --- | --- |
| `/api/public/pages/{page}` | 固定 `home` / `catalog` / `cases` / `contact` | `body` 为对应公开配置；联系由 `business_contact` 持有；空发布按空态呈现 |
| `/api/public/catalog` | 无；首版一次读取完整树 | `nodes` 的 `level` 为 `board` / `category` / `subcategory`；`counts` 按节点 ID；遵守公开顺序 |
| `/api/public/products` | `board_id`、可选 `node_id`、`q`、`page`、`page_size=20` | 关键词匹配由服务端完成；请求时编码好关键词，不在客户端扩大范围 |
| `/api/public/cases` | 可选 `tag`、`q`、`page`、`page_size=20` | 标签键来自案例页；按服务端稳定顺序展示 |
| `/api/public/products/{id}`、`/api/public/cases/{id}` | 十进制字符串 ID | 只显示新请求的公开详情，不以列表卡片代替；`404` 不重试或兜底读取旧版本 |
| `/api/public/media/{id}` | 只接受严格匹配的相对路径，再接同一个配置源 | 原生图片/预览加载失败降级；不支持外部地址、管理路径或下载逻辑作为后备 |

所有 ID 保持字符串，避免大整数失真；路由参数和媒体路径在使用前校验。接口外层失败、内容不存在和网络错误区分。正式网关按预期直接响应，验收时检查 `/api/public/` 不重定向到其他地址。媒体可见性由[服务端当前引用](../../../../app/services/public_media.py#L28-L39)决定，不由小程序推断，且不持久化图片或发布内容。

#### API 模块、路由与状态管理

公开 API 使用固定方法组，将请求函数注入 Node 测试；同生产运行时的页面脚本通过微信 API 调用。四 Tab 由原生 `tabBar` 管理。详情用 `navigateTo`；返回用原生栈，无上一页时切到对应列表 Tab。不加入权限守卫、后台页面或 HTML 渲染。状态由 `Page` 实例及其选择、分页、图片错误状态持有，用 `setData` 更新可见字段，不通过本地存储跨启动保留。

| 具体失败场景 | 影响 | 预防或处理 | 发布/回滚/监控安排 | 证据 |
