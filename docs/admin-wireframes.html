按访客看到的顺序

  1. 页头与筛选上传背景，维护说明与案例分类。“精选案例”汇总已发布案例，并非额外选品池。
  2. 第一条是重点横卡按当前筛选和排序取第一条；只展示品牌名、产品名与简短亮点。
  3. 其余进入双列网格只有一条时不显示“更多品牌案例”；零条显示空态。
  4. 详情使用案例自己的资料产品下架不撤案例；要撤回合作介绍，由发布人单独下架这条案例。
